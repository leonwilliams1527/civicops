# Phase 11 full app repair
This is the complete Phase 11 application, not a partial patch. The `app/layout.js` root layout is included, and `app/collaboration/reports/page.js` imports `read-excel-file` from its main entry.

1. Extract the ZIP.
2. Copy its **contents** into the root of your existing CivicOps GitHub repository (where package.json belongs). Do not upload the containing folder as a nested directory.
3. Keep your existing .env files and existing package-lock.json unless regenerated by npm install. Do not delete unrelated project files.
4. Run `npm install` and `npm run build` if you have a local terminal, then commit package-lock.json along with the changes.
5. Commit and push to main. Check that app/layout.js is at the repository root under app/ before deploying.
6. In Vercel verify Root Directory is the repository root (blank or `.`), and the framework is Next.js.
7. No Supabase SQL changes are required.
